Safe, User-Approved Recovery Actions

          Predefined routines with pre-execution checks, confirmation requirements, post-verification, and audit logging.
        


        
        

          
          

            

              Storage Cleanup
              Safe
            

            
Delete Temp Files (>24h)

            

              Purges accumulated temporary files older than 1 day in the Windows Temp folder. Safely skips any active files in use.
            

            
          


          
          

            

              Network Resolver
              Safe
            

            
Flush DNS Resolver Cache

            

              Clears corrupted DNS lookup entries via ipconfig /flushdns to repair broken website connections and domain errors.
            

            
          


          
          

            

              Printer Service
              Safe
            

            
Restart Print Spooler

            

              Cycles the Windows spoolsv background service to resolve stuck, frozen, or non-printing documents.
            

            
          


          
          

            

              Drive Capacity
              Irreversible
            

            
Empty Windows Recycle Bin

            

              Permanently clears deleted files from the Windows Recycle Bin to recover drive storage space.
            

            
          


          
          

            

              Network Adapter
              Safe
            

            
Renew DHCP Network Lease

            

              Requests a fresh IP lease from your router via ipconfig /renew to resolve IP conflicts and Wi-Fi drops.
            

            
          


          
          

            

              Window Manager
              Moderate
            

            
Terminate Unresponsive App

            

              Terminates a frozen or hung application window by its Process ID (PID). Protected system binaries cannot be killed.
